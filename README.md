# 📚 OdinProjects

## 🎯 Objetivo

Colocar em prática os conceitos ensinados no curso através de projetos reais, construindo um portfólio de evolução como desenvolvedor full stack — do HTML/CSS/JS fundamentais até bibliotecas e frameworks modernos.

## 🚀 Como rodar localmente

```bash
git clone https://github.com/kauacampostp/OdinProjects.git
cd OdinProjects
```

Cada projeto está em sua própria pasta e pode ser aberto diretamente (`index.html`) ou executado conforme suas instruções específicas, quando houver.
